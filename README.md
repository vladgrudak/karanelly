# KaraNelly Space — новый сайт

Статический многостраничный сайт фотостудии. Без сборки, без CMS и без зависимостей:
чистый HTML + CSS + немного ванильного JS. Загружается на любой хостинг как есть.

## Структура

```
karanelly/
├── index.html          Главная
├── space.html          Пространство (о зале)
├── gallery.html        Галерея + лайтбокс
├── booking.html        Бронирование (виджет appEvent)
├── contacts.html       Контакты и карта
├── privacy.html        Политика конфиденциальности (шаблон)
├── 404.html            Страница ошибки
├── robots.txt
├── sitemap.xml
├── .htaccess           Кэш, сжатие, 404 (для Apache)
├── content-notes.md    Что проверить и доснять перед публикацией
└── assets/
    ├── css/
    │   ├── fonts.css   @font-face для локальных шрифтов
    │   └── style.css   Все стили
    ├── js/
    │   ├── main.js     Меню, хедер, появление блоков, скелетон календаря
    │   └── gallery.js  Лайтбокс: клавиатура, свайпы, фокус
    ├── fonts/          Cormorant Garamond + Golos Text (woff2, кириллица)
    └── img/            WebP в трёх размерах, OG-картинка, иконки
```

## Локальный просмотр

```bash
cd karanelly
python3 -m http.server 8000
# открыть http://127.0.0.1:8000
```

Просто открыть `index.html` двойным кликом тоже можно, но тогда не сработают
относительные пути в некоторых браузерах — лучше через сервер.

## Публикация

1. Загрузите **содержимое** папки `karanelly/` в корень сайта (`public_html`, `www` и т.п.).
2. Проверьте, что `index.html` лежит в корне — хостинг отдаст его как главную.
3. Если Apache — `.htaccess` уже настроен: сжатие, кэш, страница 404.
   Если nginx — перенесите правила оттуда в конфиг (или попросите поддержку хостинга).
4. Включите HTTPS и редирект с `http://` и с `www`, если нужно.
5. Проверьте `robots.txt` и `sitemap.xml` после смены домена.

**Перед публикацией замените домен** `https://karanelly.space/` в:
`canonical`, `og:url`, `og:image`, JSON-LD на главной, `sitemap.xml`, `robots.txt`.
Если домен остаётся прежним — ничего менять не нужно.

## Как менять контент

- **Тексты** — прямо в HTML, каждый блок подписан комментарием.
- **Фото** — лежат в `assets/img/` с именами `g01…g14` и размерами `-640`, `-1100`, `-1600`.
  Замените файл с тем же именем и размером — вёрстка подхватит автоматически.
  Если меняете пропорции, поправьте `width`/`height` у `<img>`, чтобы не было скачков.
- **Цены и правила** — в `content-notes.md` перечислено, что нужно подтвердить у владельца.
- **Сезонный блок** («Новогоднее оформление») — секция `.season` на странице `booking.html`,
  её стоит обновлять или убирать вручную.

## Виджет бронирования

Встроен через `<iframe>` на `booking.html`:

```
https://appevent.ru/widget/embeded?widget_key=…&hall_id=9494
```

Ограничения, которые важно знать:

- стилизовать содержимое iframe нельзя — это чужой домен; можно только оформить рамку вокруг;
- в календаре 7 колонок (дни) и 13 строк (часы), на узких экранах он не перестраивается
  в мобильную вёрстку, поэтому на телефоне таблица кладётся в горизонтальный скролл
  (`.widget-scroll`), с подсказкой «прокрутите в сторону»;
- если appEvent поменяет `widget_key` или `hall_id`, правьте `src` в одном месте — `booking.html`.

Пока календарь грузится, поверх него показывается скелетон; он скрывается по событию
`load` у iframe или через 9 секунд.

## Технические решения

**Производительность.** Фото — WebP в трёх ширинах, `srcset`/`sizes`, `loading="lazy"`
для всего, кроме первого экрана. Герой предзагружается через `<link rel="preload">`
с нужным вариантом для мобильных и десктопа (`<picture>` + `media`).

**Шрифты** — self-hosted, 18 файлов woff2 с `unicode-range` (латиница/кириллица),
`font-display: swap`. Внешних запросов к Google Fonts нет — быстрее и без передачи данных.

**Адаптив** — mobile-first, контрольные точки 560 / 768 / 860 / 900 / 1040 / 1280 px.
Проверено на 360, 390, 768, 1024 и 1440 px: горизонтального переполнения нет.

**Доступность.** Ссылка «к содержанию», `aria-expanded` у меню, `inert` для скрытого меню,
focus trap в меню и лайтбоксе, управление стрелками и Esc, `prefers-reduced-motion`,
осмысленные `alt` у всех фото.

**SEO.** Уникальные `title`/`description`, Open Graph, `canonical`, JSON-LD
`PhotographyBusiness` на главной, `sitemap.xml`, `robots.txt`, семантическая разметка
(`header`, `main`, `section`, `figure`, `dl`).

## Что можно добавить позже

- CMS или генератор (Astro/11ty), если правки станут частыми: сейчас шапка и подвал
  продублированы в семи файлах — это осознанная плата за статику без сборки.
- Онлайн-оплату и предоплату (если appEvent это умеет — включить в виджете).
- Раздел с работами клиентов (портфолио по типам съёмок) — когда появятся фото людей.
- Тексты на английском, если появятся иностранные клиенты.
- Яндекс.Метрику и цели на клики «Забронировать».
